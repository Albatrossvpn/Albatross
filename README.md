# Albatross ad list

ads.srs is a sing-box rule set that blocks ad, tracker and threat
domains. It is a modified work: the lists below merged, names covered by a
parent removed, the names in build/adblock/allow.txt left out and those in
build/adblock/keep-ir.txt added, by cmd/adlist on the main branch
(.github/workflows/adblock.yml). ads.json is its source form.
